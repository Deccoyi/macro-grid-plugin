# Hello Gauge (widget example)

The smallest plugin with a custom widget: an animated gauge that follows any variable. The plugin publishes a demo value; the widget draws it on a canvas.
Copy this folder and change it to start your own widget. The widget rules (the worker, the `macroGrid` object, limits) are in
[../docs/plugin-authoring.md](../docs/plugin-authoring.md), section "Custom widgets".

Install it from the editor (Plugins, Install from Folder). It asks for the `variables` permission. Then drag "Gauge" from the Toolbox onto a page and pick a variable in its settings.
Needs Macro Grid 1.4.0 or newer.
