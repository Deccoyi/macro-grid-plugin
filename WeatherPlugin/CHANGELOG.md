# Changelog — WeatherPlugin

New features and fixes in the WeatherPlugin plugin. For technical details, see [CHANGELOG-developer.md](CHANGELOG-developer.md).

## Unreleased

## 0.1.0 - 2026-11-02
### New
- **Weather widget:** shows the current weather at a place you choose: a picture, the temperature and the wind, in °C or °F.
- **Weather variables:** the temperature, the weather code and the wind speed are also available as variables.
- **Needs Macro Grid 1.4.0 or newer.**
