# Changelog — Stream Texts

New features and fixes in the Stream Texts plugin. For technical details, see [CHANGELOG-developer.md](CHANGELOG-developer.md).

## Unreleased

### New
- First version: write live text files from variables such as CPU, RAM or your own. Point a text source of your streaming app at a file and it follows the value on its own.
- Optional browser source: show the same texts on a web page with your own styling. It is off by default and works on this PC only.
